# Apache Superset UI development

The user interface of the module: Status, Settings and About pages.
To develop it please refer to [this section of the Developer manual](https://nethserver.github.io/ns8-core/ui/modules/#module-ui-development).

```sh
cd ui
yarn install
yarn build   # or: yarn watch
```

Translations: edit `public/i18n/en/translation.json` only. The other languages come from Weblate.
